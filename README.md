# Paradise Nursery

## Project Description

Paradise Nursery is an online plant shopping
application where users can explore and purchase
different types of indoor plants.

## Features

- Browse plants from different categories.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase and decrease product quantities.
- Remove products from the cart.
- View individual and total prices.
- Responsive navigation bar.

## Technologies Used

- React.js
- JavaScript
- Redux Toolkit
- React Redux
- React Router DOM
- CSS

## Project Name

Paradise Nursery Shopping Application
